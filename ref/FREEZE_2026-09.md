## 軸間約束與評估門檻

`must` 是定義上的必然，檢查指令遵循；實際輸出只要不等於指定的
`axis_level` 就算違反，`unsure` 也不算符合。逐群計數並回報違反，不計比例。

| 強度 | `disposition` | 要求／預設的 `axis_level` | 定義 |
| --- | --- | --- | --- |
| must | `tool_injected` | `none` | 該群將移出分類母數，axis_level 問的問題對它不成立 |
| must | `service_relay` | `not_attributable` | 意圖屬於不使用本 gateway 的第三方，載荷不判 role/domain |
| must | `insufficient` | `insufficient_data` | 材料不足以判定這一群，就不足以判定任何一軸 |
| default | `batch_project` | `all_three` | 外框載明用途時用它；前綴看不出 role/domain 時改填 invocation_only |
| default | `user_envelope` | `invocation_only` | 載荷要另外抽樣才判得出 role/domain；外框已載明時可填 all_three |

`default` 是典型情況而非硬約束，評估時對每一對都計算兩個方向，並各自
標明分子與分母：

- `P(axis_level = X | disposition = Y)`
- `P(disposition = Y | axis_level = X)`

兩個方向皆至少 95% 為通過；任一方向落在 90%（含）至 95%（不含）為
「要看，但不擋」；任一方向低於 90% 為「這一批判定不可信」。任一方向的
分母小於 `MIN_GROUP_SIZE` 時不算百分比，只報原始計數。
