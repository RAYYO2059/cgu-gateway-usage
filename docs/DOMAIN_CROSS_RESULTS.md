## 門檻與執行完整性

Opus（`claude-opus-5`）與 Codex（`gpt-5.6-sol`）各完成 600/600，最終輸出均無缺列、重複 sha256、樣本外 sha256 或非零外部工具事件。兩側 domain 完全相同 **495/600（82.5%）**，達到 [事前凍結的 0.75 門檻](../ref/FREEZE_2026-09.md)。分流層的 53.4%（n=58）僅作背景參照，不參與此門檻。上限校準的 Opus 自我一致率參照是 22/25（88%，判讀精度 ±8pp）；82.5% 與該小樣本參照接近，但不能由此推出分類正確率。

兩側的逐筆 user prompt 均由同一 `build_prompt()` 產生，字元上限 1,200、字典渲染與 JSON schema 相同；模型、CLI 與執行端固有的 host instructions 不同。Opus 本地請求設定指紋為 `2f651b15de5086693cf30afc37385e2c360eba759b912ea8ddd5b6f2cfc12490`；Codex 提示詞配方指紋為 `0676d93e4dba38b5e52eaaae2eedd6d8ee2c9b0bd44693eb146009cfcf393e1c`，執行指紋為 `7d1928d7c3718cebf83a14a3830362615fba8a46ca3d132978d0c2e6c8af6bb2`（`codex-cli 0.153.4`）。兩側指紋的涵蓋範圍不同，不能以雜湊值不同推論 user prompt 不同。

正式 600 筆中有 **281 筆（46.8%）**在 1,200 字元截斷。Opus 最終輸出失敗 0、工具事件 0；Codex 最終輸出失敗 0、工具事件 0。Opus `prompt_tokens_total` 最小值 **3,158**，缺值 0。Opus 成功列的 CLI 回報估算成本合計 **US$23.680861**；先前未寫入結果的失敗嘗試不在此數，且此數不併入資料集牌價等值成本 US$2,749.32。

`named_third_party=true`：Opus 23 筆、Codex 29 筆、交集 16 筆、聯集 **36 筆**。這是模型標記的計數，沒有人工核對。供 Ray 在自己的終端審查的聯集清單是 repo 外 `_rescued_scratchpad/domain_named_third_party_union.csv`，恰好只有 `prompt_text_sha256,source_path` 兩欄；本報告不列逐筆識別碼、路徑或內容，也不標出由哪個模型標記。

設層 `h` 的抽樣率 `f_h=n_h/N_h`、總相異內容 `N=17,365`、樣本變異數 `s²` 以 `n_h−1` 為分母。內容比例的分層設計變異數估計為 `Σ_h (N_h/N)²(1−f_h)s²_{h,1[domain=c]}/n_h`。請求比值以 `z_i=r_i(1[domain_i=c]−Ŷ_c/T̂)` 線性化，變異數估計為 `Σ_h N_h²(1−f_h)s²_{h,z}/(n_h T̂²)`；95% CI 為點估計 ±1.96 個標準誤，端點限制在 0–100%。這些區間**只計抽樣設計的不確定性**，不含模型誤判、兩模型不一致、`prompt_text` 不完整或截斷偏差；對長尾請求數的常態近似也需審慎。

已知 eligible 母體實際有 **58,100 筆請求**；`T̂=61,466.13`，高出 **3,366.13（5.8%）**。上一版的 61,466.14 是把八個已捨入至兩位的小計相加；本版從未捨入的小計計總數。這是樣本重複次數的估計誤差；表中加權請求數不可稱為已觀測的全體分類請求數。八值在樣本中均至少 10 筆，**沒有值落到 `MIN_GROUP_SIZE=10` 以下**；加權後的估計內容數也都超過 10，但不能用估計筆數取代實際樣本 n 通過門檻。

## `unknown` 的報告處置

`unknown` 有 **63/600（未加權 10.5%）**，其母體相異內容占比估計 **9.9%（95% CI 7.7–12.1%）**；這是「無法判定用途的比例」，不是第七種具體用途。它不出用途結論，不拆解，也不重新分配到其他值。兩模型對此值同判 32/63（50.8%）；Opus 的 67 個 `confidence=low` 中有 35 個落在此值（52.2%）。

只排除 Opus 判為 `unknown` 的 63 筆後，兩模型 domain 同值 **463/537（86.2%）**。校準中內容相同、同期重跑的 Opus 自我一致參照為 22/25（88%，一筆等於 4pp，精度約 ±8pp）。86.2% 在該不精確參照附近，但兩個數字的母體、抽樣與比較對象不同，**不能據此證明剩餘不一致全是任務雜訊、也不能排除模型差異**。因此不以此比較修改門檻或重新分配 `unknown`。

## `not_applicable` 事前預期為零：尚未釐清
